IT workstation provisioning

Prepare a new Windows PC.

Run one command to install the setup prerequisites and open the workstation toolkit. Then choose the setup your PC needs.

Start from Command Prompt

  1. Open Command Prompt using Run as administrator.
  2. Copy the command below, paste it into CMD, and press Enter.
  3. Wait for the application to open, then choose Normal Setup or CNG Setup.

Requires internet access. Git, Python, and Microsoft App Installer are installed if needed. Accept a Windows administrator prompt if shown.

Category 1

Normal Setup

Install OBS Studio, AnyDesk, TeamLogger, Zoom, Microsoft Teams, WinRAR, Microsoft Office, and RustDesk.

Category 2

CNG Setup

Install Front desktop and Microsoft Windows App. Selecting this category sets the Windows timezone to Sydney.

If a download fails, check your internet connection and Windows date/time, then run the command again. In the toolkit, use Check / Sync Time and Retry Last Task after fixing an error. Microsoft Office may display its own setup window.
